# 🌸 Iris Flower Data Visualization

## 📌 Project Overview

This project focuses on exploring and visualizing the Iris Flower Dataset using Python. The goal is to communicate important patterns, compare flower species, and understand relationships between numerical features through clear and meaningful charts.

## 🎯 Objectives

- Explore the Iris Flower Dataset.
- Create at least five meaningful visualizations.
- Compare flower measurements across species.
- Identify distributions, trends, and relationships.
- Present findings using readable charts with titles and labels.

## 🛠️ Tools and Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📊 Visualizations

The project includes the following charts:

1. **Bar Chart:** Compares average petal length across flower species.
2. **Line Chart:** Compares average flower measurements by species.
3. **Pie Chart:** Displays the distribution of records by species.
4. **Histogram:** Shows the distribution of petal lengths.
5. **Scatter Plot:** Explores the relationship between sepal length and petal length.
6. **Correlation Heatmap:** Visualizes correlations between numerical measurements.


Open `task_03_iris_data_visualizations.ipynb` and run the cells.
